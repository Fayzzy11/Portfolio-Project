06

Cleaning rules

Prices

Weekly Friday grid; Tel Aviv lines stamped on Sundays moved to the Friday before. Gaps up to eight weeks bridged; a held line that stops trading earns 0% after its last price.

Dividends

Event study on ~38,000 ex-dates: the price does not drop on ex-date, so PX_LAST already includes dividends. Dividend records only size the withholding-tax haircut.

Fundamentals

Year-end + 6 months and never before announcement (471 late filers blocked). Negative sales and EV ≤ 0 set to missing; negative book kept.

Issuers and liquidity

One line per issuer (share classes and dual listings merged on identical accounts, the most traded kept). Liquidity filters remove 466 of 14,369 member-dates, de-duplication 199 more.

Anti-bias checklist

Written before the backtest was interpreted. Rule one: if a result looks good, check survivorship, look-ahead and units before any other explanation.
