Process

How every strategy is tested

The same four steps for each study, so results can be trusted and compared.

  1. Economic hypothesis

    A documented reason for the premium to exist, backed by the academic literature.

  2. Rules fixed in advance

    Universe, signals, sizing, costs and sample split written in the code before any result is seen.

  3. Backtest with costs

    Bloomberg data with roll adjustment checks, no look-ahead, trading and roll costs included.

  4. Out-of-sample validation

    A period never used in design, every variant published, and a frank list of limitations.
